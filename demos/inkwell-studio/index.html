The gallery — your UI

Panels, images and captions are your app’s components. The swarm returns each panel as data (image + caption + status); your front-end lays out the storybook.

The Crew — the swarm made visible

The differentiator: you watch the Critic reject a panel and the Writer revise it. Agents improving each other’s work is the whole show.

The revision loop — why a team

A single AI hands you one draft, take it or leave it. The Critic↔Writer loop is what turns a rough panel into a good one — and it needs separate agents to exist.

Path 2 notes: this studio is a standalone app talking to JiuwenSwarm over A2A, so your front-end renders these panels from the swarm’s JSON (A2UI isn’t used — that’s the trade for the cleaner “embedded engine” story). Phase 1 plays a scripted run so we can lock the UX; the same UI is driven by a normalized event stream, so Phase 2 just swaps the simulated source for a real A2A stream.
